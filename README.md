# Presentación - Landing Page: Armamento recolectado

## Descripción del proyecto

Este proyecto consiste en una landing page desplegada en GitHub Pages que presenta un catálogo de armas organizadas en formato de tarjetas. El objetivo es representar información estructurada de forma visual, aplicando principios de diseño de componentes reutilizables y separación entre estructura y estilos.

## Arquitectura del proyecto

El proyecto se organiza en una estructura modular basada en componentes:

- Encabezado principal de la página
- Contenedor central del catálogo
- Tarjetas de armas como unidades reutilizables de información

---

## Enfoque de diseño

El sistema está basado en:

- Componentes reutilizables
- Separación de responsabilidades entre contenido y estilos
- Escalabilidad para futuras expansiones del catálogo
- Consistencia visual en todos los elementos
